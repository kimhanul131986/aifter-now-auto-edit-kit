# 04. 검수

`npm run render` 다음에 붙여 넣으세요. 자동 검사가 0건이어도 사람 눈에만 보이는 오류가 있으니 이 단계는 꼭 하세요.

```
npm run review 를 돌리고 review/shots.jpg, review/chapters.jpg 를 직접 봐 줘. 칸마다 아래를 확인하고, 문제를 시각과 함께 적은 뒤 고쳐서 다시 렌더해.

- 글자끼리 겹침, 글자가 숫자·그림과 겹침
- 화면 밖으로 잘린 글자
- 비어 있는 그래픽 화면, 아직 나오면 안 되는 요소가 미리 보임
- 자막이 얼굴 눈·입을 가림
- 같은 화면처럼 보이는 장면이 연달아 나옴
- 화면 속 숫자가 실제 값과 다름

고친 뒤 npm run render → npm run review 를 다시 돌려 같은 칸을 확인해 줘.
```
