# 01. 잘 된 릴스 해부하기 (선택)

따라 하고 싶은 릴스를 휴대폰으로 화면 녹화해 `reference.mp4`로 저장한 뒤, 키트 폴더에서 Claude Code에 아래를 붙여 넣으세요.
다른 사람 영상은 분석용으로만 쓰고 내 영상에 그대로 넣지 마세요.

```
reference.mp4 를 초 단위로 해부해 줘. 다음 순서로 실제로 실행하고, 측정값만 써 줘.

1. ffmpeg로 0.5초마다 프레임을 뽑아 8×2 시트로 묶고 전부 직접 봐.
2. 장면 변화 검출: ffmpeg -i reference.mp4 -vf "scale=270:-1,select='gt(scene,0.06)',showinfo" -f null -
   0.4초 안쪽 중복은 합치고, 전환 횟수와 평균 간격을 계산해.
3. .venv-asr 파이썬으로 reel/transcribe.py 를 돌려 단어 시각 전사를 만들어.
4. 0.5초 표본마다 화면 구성을 분류해: 얼굴만 / 위 그래픽+아래 얼굴 / 그래픽만. 비율(%)을 계산해.
5. 얼굴만 나오는 장면이 어떤 말(접속어·단락 시작)에서 나오는지 적어.
6. 문장마다 화면에 나온 "물건"(미터, 터미널, 목록, 휴대폰, 말풍선 …)을 적고, 같은 물건이 연속되는지 봐.
7. 카운트업처럼 움직이는 숫자는 마지막에 멈춘 값만 써. 중간 프레임 값을 쓰지 마.

결과를 reel/engine/rules.default.json 형식에 맞춘 rules.json 으로 만들어 줘
(shot.target, mix.F/S/G, faceFull, motion 은 그대로 두고 측정값만 바꿔).
```
